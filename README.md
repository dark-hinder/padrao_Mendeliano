
# 🧬 Protótipo de Simulação Genética

Este projeto é um protótipo desenvolvido como parte de um projeto maior voltado à exploração de conceitos biológicos por meio da programação.

A proposta foi criar uma simulação visual na qual organismos descendentes são gerados a partir de regras genéticas implementadas em Python, relacionando informações genéticas com características visuais.

## 🎯 Objetivo

Desenvolver e testar uma representação computacional de herança genética, utilizando organismos com características visuais determinadas por suas informações genéticas.

**O objetivo inicial do protótipo foi concluído**, alcançando o resultado visual e funcional esperado.

## ⚙️ Tecnologias utilizadas

- **Python** — implementação da lógica
- **Pygame** — interface gráfica e visualização
- **Git e GitHub** — versionamento e documentação

## 🧪 O que foi desenvolvido

- Geração de organismos descendentes
- Implementação de regras próprias de herança genética
- Conversão de informações genéticas em proteínas e códons
- Representação visual dos organismos por cores RGB
- Interface gráfica para acompanhar os resultados da simulação

## 📚 Contexto científico

Este protótipo foi desenvolvido para fins de estudo e experimentação.

As regras genéticas utilizadas são simplificações computacionais definidas para o modelo. Portanto, os resultados representam o comportamento do sistema implementado, e não uma simulação completa dos mecanismos genéticos reais.

## 🔭 Contexto do projeto maior

Este protótipo representa uma etapa de um projeto maior que busca explorar a relação entre **biologia, programação e modelagem computacional**.
